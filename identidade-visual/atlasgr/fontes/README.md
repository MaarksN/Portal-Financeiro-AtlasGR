# Fontes AtlasGR

## Mont - família primária

A Mont é uma fonte comercial. O próprio manual informa que a licença deve ser adquirida e que o compartilhamento sem compra constitui pirataria; por isso, os binários não foram copiados para este pack.

Fonte oficial indicada pelo manual: <https://www.fontfabric.com/fonts/mont>

Pesos necessários: Black, Heavy, Bold, SemiBold, Regular e Light.

## Montserrat - família secundária

A Montserrat é gratuita e deve substituir a Mont quando houver restrição técnica ou de licenciamento.

Fonte oficial indicada pelo manual: <https://fonts.google.com/specimen/Montserrat>

Pesos necessários: Black (900), Bold (700), SemiBold (600), Medium (500), Regular (400) e Light (300).

Para uso web conectado, importe `montserrat-web.css`. Para ambiente offline, baixe os arquivos no Google Fonts e hospede-os no próprio projeto respeitando a licença que acompanha a família.
