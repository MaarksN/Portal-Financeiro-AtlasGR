# Pack de identidade visual

Este diretório centraliza os assets oficiais e as regras de aplicação da AtlasGR usadas neste repositório.

## Marca disponível

- `atlasgr/`: logo SVG/PNG, símbolo, ícones, paleta, tipografia, tokens, padrões e preview.

Abra `atlasgr/preview.html` no navegador para uma conferência visual rápida. O README da marca contém regras, tamanhos mínimos, licenciamento de fontes e referências de páginas do manual.

## Observação de licenciamento

Fontes comerciais ou distribuídas por terceiros não foram extraídas do PDF. O pack indica as fontes oficiais e os links de aquisição, evitando redistribuição sem licença.
